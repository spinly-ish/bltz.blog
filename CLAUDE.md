# bltz.blog — Claude Code context

## О проекте

bltz.blog — ориентационная витрина приложений. Помогает пользователю **за 30 секунд** получить готовую рекомендацию «что поставить», без перегрузки выбором. **Кроссплатформенная** (macOS, iOS, Windows, web) — привязки к конкретной ОС на уровне сайта нет, платформа указывается на карточке приложения.

Ключевые сегменты AJTBD: VPN, New Mac / Windows switchers, оптимизация устройств, диктовка голосом. Подробнее: `docs/Маркетинг/Product_Strategy.md`.

## Стек

- **Frontend:** React 18 + Vite 5, React Router 7
- **i18n:** собственный `LanguageContext` (без библиотек), EN по умолчанию, `/ru` — русская версия
- **Стили:** один `src/index.css` с CSS-variables (тёмная/светлая темы)
- **Формы:** Formspree (`/submit`)
- **Аналитика:** Amplitude (встроена в `index.html`)
- **Хостинг:** GitHub Pages, кастомный домен `bltz.blog`

## Принципы работы

- **Позиционирование** — кроссплатформенное, не «iOS apps». Hero-месседж: *«Find the right app/tool/workflow in 30 seconds»*.
- **SEO — главный канал привлечения.** Каждое изменение URL / мета-тегов / контента оценивается через призму «что увидит Google».
- **Киллер-фичи:** короткое демо-видео на карточке, одна рекомендация вместо топ-10, scope reduction (скрыть лишнее).
- **i18n SSoT:** `src/data/appsData.js` — английская база; `src/i18n/appsData.ru.js` — только переводимые поля по `app.id`.
